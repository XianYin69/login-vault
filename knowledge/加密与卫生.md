# 加密与卫生

## 本库的加密构成

- KDF：PBKDF2-HMAC-SHA256，310,000 次迭代，16 字节随机盐（OWASP 2023 量级；更高安全预算可换 argon2id/scrypt）。
- 加密：Fernet = AES-128-CBC + HMAC-SHA256 认证加密（密钥由 KDF 输出 base64url 派生），密文自带完整性校验，篡改即解密失败。
- 主密码**永不落盘**：磁盘只有 salt.bin 与 vault.json.enc。忘记主密码 = 数据不可找回（设计如此，不是缺陷）。

## 锁定与审计

- 解密失败计数存 fail.json；连错 ≥5 次锁 60 秒，挡住脚本爆破。
- audit.log 追加式记录 init/add/get-masked/get-reveal/rm/rotate/list——谁在何时取出过明文可回溯。

## 口令卫生

- 一站一密（--gen 随机 12-64 位、四类字符）；撞库时损失单点。
- 轮换：rotate 一键换新随机密 + rotated 时间戳；建议敏感站点季度轮换。
- 熵参考：20 位四类随机 ≈ 120+ bit 熵，足够；主密码建议 ≥5 随机词或 ≥16 混合字符。

## 反模式

- 把密码/库文件写进 git、云盘、聊天窗口；`--secret` 传参进 shell 历史（用交互 getpass）。
- note 里放助记词/私钥/恢复码等**不可重置**秘密——这类只做离线冷备份，不进任何联网机器。
- 多设备同步明文导出；确需同步只同步 vault.json.enc 密文。
